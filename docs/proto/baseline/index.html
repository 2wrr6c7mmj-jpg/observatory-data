平常帯と起こりにくさ試作

日々の機数・艦艇数・公務船・中間線越え等について、曜日と季節の癖を除いた「平常の幅」を引き、その幅を上に外れた日と、その件数が平常の下でどれほど起こりにくいかを示します。

これは警報ではなく目安です。「およそ N 日に1回」は下に書いた統計モデルの仮定の下での数字で、実際の頻度や意図を表すものではありません。1,400日ほどを毎日見ているので、「およそ 1,000 日に1回」の日は偶然でも1〜2日は現れます。

何が分かるか

  • その時点の直近の水準・曜日・季節から見て、ふだんより多かった日（帯の上に出た点）。
  • その日の件数がどのくらい珍しいか（負の二項分布による上側確率を「およそ N 日に1回」に直したもの）。

手法

  1. 尺度：件数 y を log(1+y) に直してから計算します。件数が少ない時期と多い時期で、ばらつきの大きさをそろえるためです（件数に戻すと幅は上下非対称になります）。
  2. 水準：その日を含まない過去56日の値の中央値（値が20日以上ある場合のみ）。過去だけを使うので、その日の値や演習の影響が自分の平常に入りません。
  3. 曜日・季節：水準からの差の中央値を曜日ごとに求めて引き、次に月ごとの中央値を求めます（それぞれ中央値で中心化）。表では倍率で示します。月の効果は全期間（約4年）から求めるため、ここだけは後の年の情報も使っています。STL の考え方を、外れ値に強い中央値で置き換えたものです。
  4. 平常値と幅：平常値 ＝ 水準＋曜日効果＋月効果（log の上で足し、件数に戻す）。幅は、過去56日の残差の MAD（中央絶対偏差、×1.4826 で標準偏差に換算、最小0.15）の±3倍。上限を超えた日を「平常を外れた日」としました。
  5. 起こりにくさ：平均＝平常値の負の二項分布で、その日の件数以上になる確率 p を求め、1/p を「およそ N 日に1回」と表示します。分布の形（size、小さいほど裾が重い）は、その日より前の365日の「平常値と実際の値」の組から最尤で選び、30日ごとに当て直します。
  6. 当てはまりの確認：上の「p<0.01 の日の割合」は、モデルが正しければ約1%になるはずの値です。これより大きければ、表示する N は実際より大きめ（珍しく見えすぎ）です。
  7. null（記載なし）と日報がない日は計算に使わず、0 とはみなしません。

限界

  • 過去56日の中央値を使うため、高い水準が数週間続くと平常の側が追いつき、外れが出にくくなります（持続については4を参照）。
  • 中間線越え等・公務船は null が多い指標です。null の日の多くは「0 に近い日」とみられるので、記載のある日だけで作った平常は高めに出ます。公務船は記載の始まった 2024年5月以降だけが対象です。
  • 日々の値を互いに独立とみなしています。実際には多い日は続きやすく（4）、また負の二項は裾の重さを十分に表せないため、N は大きめに出がちです。N は桁の目安として読んでください。
  • 日報は前日 06:00〜当日 06:00（UTC+8）の集計で、曜日は報告日の曜日です。
