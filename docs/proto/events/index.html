大規模演習のイベントスタディ試作

2022年11月以降の大規模演習の初日を0日目にそろえ、その前30日から後10日までの各指標を重ねます。演習の前に、ふだんと違う動きが共通して見られるかを確かめるためのものです。

事例は数件しかありません。この図から「前兆がある」「前兆がない」と言い切ることはできません。1事例を除くと結果がどう変わるか、演習と関係のない日を起点にした場合（偽の起点）とどう違うかを並べています。

何が分かるか

  • 演習の0日目に向けて各指標が上がっていくのか、それとも当日に急に跳ねるのか。
  • 直前7日（−7〜−1日）の水準が、その前（−30〜−8日）と比べて高いか。それが、偶然の日を起点にした場合の分布のどこにあるか。

対象とした演習

手法

  • 0日目：演習の開始日を含む最初の日報（日報は前日 06:00〜当日 06:00 UTC+8 の集計なので、開始日の翌日付の日報）。開始が早朝の場合は1日ずれることがあります。
  • 重ね方：−30〜+10日の各日について、事例の値の中央値と最小〜最大を描きます。null・日報なしは除きます。
  • 直前の比：(−7〜−1日の中央値＋0.5) ÷ (−30〜−8日の中央値＋0.5)。値が4日・12日以上ある事例だけ。
  • 偽の起点：どの演習の0日目からも45日以上離れたすべての日を0日目とみなして同じ比を求め、その分布（5%・50%・95%）と、演習の比の中央値がその分布の何%点にあたるかを示します。
  • 1事例を除く：各事例を除いて中央値の線と比の中央値を計算し直し、0日目より前で中央値の線が最大どれだけ動くかを示します。
  • 演習の選び方：開始日を公開情報で確かめられたものだけを入れ、出典の URL をデータ（analysis/exercises.json、ページの元データ events.json）に残しています。

限界

  • 事例が少なく、演習の規模・形式（名称の有無、発表の有無、期間）がそろっていません。中央値は1件で大きく動きます。
  • 演習期間中、国防部は日報とは別に臨時の発表を出し、計上範囲が異なる数を示すことがあります。ここで使うのは日報だけです。
  • 公務船は記載が 2024年5月以降で、古い事例は欠けます。中間線越え等も null の日があり、事例によって使える日数が違います（1）。
  • 「前兆」の有無は、ここで見ている4指標の、日単位の公表値についてだけの話です。衛星画像・通信・政治日程などの他の情報は含みません。
