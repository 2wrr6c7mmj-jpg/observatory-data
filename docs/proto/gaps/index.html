収集の穴と沈黙試作

台湾国防部の日報について、日ごとに「数値がある」「日報はあるが読み取れなかった」「日報が見当たらない」「日報はあるがその指標の記載がない」を区別して示します。

何が分かるか

  • グラフの低い値が「活動が少なかった」のか「公表がなかった・取れなかった」のかを、日単位で見分けられます。
  • 指標ごとに、日報に記載され始めた時期が違います。記載が始まる前の空白は「ゼロ」ではなく書式上の未記載です。

暦

セルにカーソルを当てると、その日の日報の件数・値・読み取れなかった日報の番号が出ます。

手法

  • 期間は daily.csv の最初の日から最後の日までの暦日。各日を次の順で分類します。
    1. 数値あり：daily.csv に行がある日。指標ごとに、値（0 を含む）か null（原文に記載なし）かを分けます。
    2. 日報はあるが読み取れず：reports.json にその報告日の日報があるが、すべて parsed:false（多くは本文が画像のみ）。status.json の unparsed_ids と同じものです。
    3. 日報が見当たらない：その報告日の日報が一覧に無い日。
  • 「記載が始まった日」は、その指標に初めて値が入った報告日です。それより前の null は書式上の未記載として別の色にしています。

限界

  • 公表の遅れは測れていません。daily.csv の retrieved_utc は取得（遡り取得を含む）の時刻で、公表時刻ではありません。日報の原文にある発表時刻（例：09:00 UTC+8）は今の取得では列にしていないため、遅れの分布は出していません。
  • null は「記載が無い」ことしか意味しません。たとえば中間線越えの null の多くは「越えた機がいなかった」可能性が高いですが、原文に明記がないので 0 にはしていません。軍機が null の日も、本文に艦艇しか書かれていない日（機数が0とみられる日）を含みます。
  • 「日報が見当たらない」は、国防部が出さなかった場合と、一覧の取得漏れの両方を含みます。区別には一覧ページの再確認が要ります。
  • 大規模演習の期間に出る臨時の発表は日報とは別の集計で、ここでは数えていません。
