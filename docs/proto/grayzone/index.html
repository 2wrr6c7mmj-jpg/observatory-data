グレーゾーンの一覧：尖閣の中国海警と台湾周辺の公務船試作

軍ではない公船による圧力を、日本側（海上保安庁）と台湾側（台湾国防部）の発表から日ごとに並べます。2つは数える範囲も基準も違うため、足し合わせません。

何が分かるか

  • 尖閣諸島周辺の接続水域に入った中国海警局の船舶等の隻数と、そのうち領海に侵入した隻数（海上保安庁）。
  • 台湾国防部の日報が台湾周辺で確認したとする中国の公務船の隻数。
  • 両方が同じ時期に増えているか・片方だけかを、同じ日付の軸で見比べること。

日ごとの表（新しい順、直近60日）

手法

  • 値は公開データをそのまま並べています（計算はしていません）。空欄は「記載なし・取得できず」で、0 とはみなしません。
  • 海上保安庁の空欄の扱い：
  • 台湾国防部の公務船は、日報に公務船の記載が始まった後も、記載のない日があります（その日は空欄）。

限界

  • 日付の区切りが違います。海上保安庁は日本時間の暦日、台湾国防部の日報は台湾時間の前日6時〜当日6時。
  • 海域が違います。海保は尖閣の接続水域・領海だけ、台湾国防部は台湾周辺の広い範囲で、場所の内訳は公表されていません。同じ船が両方で数えられている可能性もあります。
  • どちらも当事者側の発表で、確認・公表の基準は発表する側に依存します。中国海警局は別に「巡航」として発表することがあり、日付・隻数は一致しません。
  • 打上げ告知と実際の打上げの照合（当初の案9）は、NOTAM Watch から抜いた告知（docs/data/launches/）がまだ公開データに入っていないため、代わりにこの一覧を作りました。
