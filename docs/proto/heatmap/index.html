海峡×月の通過件数と年ごとの変化試作

統合幕僚監部が公表した中国艦・ロシア艦の海峡の通過を、海峡と月の格子で数えます。年ごとの増減は、前年との率の比とその信頼区間で示します。

何が分かるか

  • どの海峡が、いつ、どれだけ使われたか（公表された件数）。季節の偏りと年による変化。
  • ある年の件数が前年より多い・少ないと言えるか（率の比の 95% 区間が 1 をまたぐかどうか）。
  • 海峡名が本文になく推定した通過（推定）と、本文に海峡名がある通過（明記）を分けて見られます。

年ごとの表

手法

  • 件数の単位：公開データ passages.csv の1行（1資料×1海峡×1日）。後の資料が前の通過を再び書いたもの、推定の行で同じ資料に明記の通過があるものは、元のデータの段階で除いてあります（meta.json の重複の除去）。
  • 国：中国の資料・ロシアの資料はその国。中露を1つにまとめた資料の行は、艦級名（jso/ref/vessel_classes.csv）から国を判定し、両国の艦が入っていれば両方に数えます。そのため中国とロシアの件数を足すと行数より多くなります。
  • 率の比：その年の件数 ÷ 観測日数 を、前年の同じ値で割ったもの。観測日数は最初の公表日（2007-07-04）から最後の公表日までで、途中の年（最初と最後の年）は日数で補正します。95% 区間は、2年の件数の合計を固定したときの二項分布の正確な区間（Clopper-Pearson）を率の比に換算したもの。件数が 0 の年でも区間は出ます。

限界

  • 件数は公表された通過の数で、実際の通過数ではありません。統幕の公表基準（どの艦種・どの海域を公表するか）は年によって変わりうるため、古い年との比較は公表方針の変化を含みます。
  • 率の比の区間は、通過が互いに独立に起きる（ポアソン）と仮定しています。実際は艦隊がまとまって複数の海峡を通るので、ばらつきは仮定より大きく、区間は狭すぎます。1 をわずかに外れた程度の比は、強い根拠になりません。
  • 前年との比だけを示しており、多くの年・海峡を同時に見ると、偶然に 1 を外れる組が出ます（多重比較の補正はしていません）。
  • 推定の通過は、基準地・距離・針路と「〜から〜に向けて」の海域から海峡を推定したもので、誤りを含みえます。
  • 資料は手作業で追加しているため、最後の公表日より後は空です（自動の取得はできない）。
