分析の試作試作・採用前

台湾国防部の日報（2022年11月〜）、統合幕僚監部の海峡の通過の公表、海上保安庁の尖閣の発表から、中国軍などの東アジアでの動静が「平常を超えているか」を、根拠と手法を明示して示すための試作です。1〜5 は台湾国防部の日報、6〜8 は統幕の資料、9〜10 は複数の出典を使います。どれも警報ではなく、読む人が自分で確かめるための目安です。

まだ採用を決めていない試作です。表示や数値の出し方は変わることがあります。各ページに手法・限界・データの版・出典を書いています。

1. 収集の穴と沈黙

欠けた日、null、読み取れなかった日報を暦で。「活動なし」と「公表なし・取得できず」を分けて見る。

2. 平常帯と起こりにくさ

曜日・季節を除いた頑健な平常の幅と、その日の件数が「およそ何日に1回」か。

3. 変化点と定義変更

週の水準の段差を検出し、日報の定義変更・記載の割合の変化と重ねる。

4. 艦艇の持続度と中間線越えの割合

「多い日」の連続日数の分布といまの連続、中間線越え等の割合と Wilson 区間。

5. 大規模演習のイベントスタディ

演習初日を0日目にそろえた前後の動き。1事例ずつ除いた結果と偽の起点との比較。

6. 海峡×月の通過件数

中国艦・ロシア艦の海峡の通過を格子で。前年との率の比と正確な信頼区間。推定の通過を区別。

7. 自国側の海の外での滞在日数（行先別）

進出→帰投の往復の日数を年ごとに Kaplan-Meier で。行先（太平洋／その他）と、明記の組・艦番号による推定の組を区別。

8. 中露の共同行動の候補

「共同」の明記・同じ記述・時期の重なり（±2日・同じ海峡・同じ向き）の3段。日付をずらした比較つき。

9. グレーゾーンの一覧

尖閣の中国海警（海保）と台湾周辺の公務船（台湾国防部）を日ごとに並べる。足し合わせない。

10. 複数の指標の同時の上振れ

シナリオごとに、各指標の過去1年でのパーセンタイルが90を超えた数と一覧。重みや閾値は付けない。

共通の約束

  • 原文に記載のない数値（null）は 0 とみなしません。
  • 計算は GitHub Actions（proto.yml）が台湾・海保の収集の後に行い、結果を JSON（gaps.json・baseline.json・changepoints.json・persistence.json・events.json・heatmap.json・stay.json・joint.json・grayzone.json・iw.json）に書き出します。ページはその JSON を読んで描くだけで、外部のライブラリは使っていません。
  • 計算の中身：analysis/proto.py（1〜5）・analysis/proto2.py（6〜10）
  • 統幕の資料は手作業で追加しているため、6〜8 と 10 の統幕の指標は、資料の追加の後の最初の計算で更新されます。
