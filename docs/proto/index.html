分析の試作試作・採用前

台湾国防部の日報（2022年11月〜）から、中国軍の台湾周辺での動静が「平常を超えているか」を、根拠と手法を明示して示すための試作です。どれも警報ではなく、読む人が自分で確かめるための目安です。

まだ採用を決めていない試作です。表示や数値の出し方は変わることがあります。各ページに手法・限界・データの版・出典を書いています。

1. 収集の穴と沈黙

欠けた日、null、読み取れなかった日報を暦で。「活動なし」と「公表なし・取得できず」を分けて見る。

2. 平常帯と起こりにくさ

曜日・季節を除いた頑健な平常の幅と、その日の件数が「およそ何日に1回」か。

3. 変化点と定義変更

週の水準の段差を検出し、日報の定義変更・記載の割合の変化と重ねる。

4. 艦艇の持続度と中間線越えの割合

「多い日」の連続日数の分布といまの連続、中間線越え等の割合と Wilson 区間。

5. 大規模演習のイベントスタディ

演習初日を0日目にそろえた前後の動き。1事例ずつ除いた結果と偽の起点との比較。

共通の約束

  • 原文に記載のない数値（null）は 0 とみなしません。
  • 計算は GitHub Actions（proto.yml）が台湾の収集の後に行い、結果を JSON（gaps.json・baseline.json・changepoints.json・persistence.json・events.json） に書き出します。ページはその JSON を読んで描くだけで、外部のライブラリは使っていません。
  • 計算の中身：analysis/proto.py
