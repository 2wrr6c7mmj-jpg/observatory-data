複数の指標の同時の上振れ（兆候と警報の試作）試作

シナリオごとに関係しそうな指標を並べ、それぞれをその指標自身の過去1年の分布の中で位置づけます（パーセンタイル）。90 を超えた指標がその日にいくつあったかと、その一覧を示します。重み付け・合成点数・「何件そろったら危険」といった閾値は付けません。

何が分かるか

  • ある日に、普段より多い（過去1年の上位10%を超える）指標がいくつ同時に出ていたか。
  • どの指標が上振れていたか、値は何か、比べられる指標がその日にいくつあったか（欠測の日は数えない）。

指標はシナリオに「関係しうる」ものを選んだだけで、シナリオが起きている・起きることを判定するものではありません。上振れた指標の数は、指標の数・欠測の多さ・指標どうしの相関（同じ出来事が複数の指標に現れる）に左右されます。

上振れた指標の一覧（新しい順）

指標

手法

  • パーセンタイル：その日を含まない直前 日のうち値のある日（ 日以上ある場合だけ）を参照の分布とし、その日の値より小さい日の数＋同じ値の日の数の半分を、参照の日数で割って 100 倍（中央順位）。0 が多い指標で、ふつうの 0 が高いパーセンタイルにならないようにするためです。
  • 上振れ：パーセンタイルが を超えた指標。数は、その日に値のあった指標の中で数えます。値がない（日報なし・記載なし・データの期間外）指標は「比べられない」とし、0 とも上振れなしともみなしません。
  • 統幕の通過：通過日の7日（中露の同じ記述は30日）の合計。資料は通過の翌日ごろに公表されるため、最後の公表日の前日までを値のある日とし、それ以降は比べられない日とします。
  • 台湾国防部：2022年11月以降の台湾周辺全体の書式の日だけ（それ以前は数える範囲が違う）。

限界

  • 参照は直前1年なので、水準が上がり続けている時期は上振れが出にくく、下がった後は出やすくなります。「その時点の1年と比べて多い」という意味です。
  • 7日の合計は日をまたいで重なるため、1回の通過が7日間続けて上振れとして数えられます。
  • 統幕の資料は手作業で追加しているため、追加が遅れた期間は比べられない日になります。海上保安庁のデータが公開データに入るまでは、その指標は比べられません。
  • 台湾国防部の公務船と中間線越え等は、記載のない日が多く（越え・確認がなかった日の可能性が高いが、原文に数の記載がない）、記載のある日だけで分布を作ります。上振れがどちらにずれるかは分かりません。記載のある日だけを比べるので、記載の出る日の増減（出る日が多くなること自体）は捉えられません。また比べられる期間が短く（公務船は 2026-07 以降）、参照の日数が少ないうちは結果が不安定です。
  • 統幕の公表の無い日を0件として数えています。資料の取りこぼし（公表はあったが資料に入っていない）と、通過が無かった0を区別できません。
  • 指標の選び方は試作で、根拠のある重みや閾値を与えるものではありません。
