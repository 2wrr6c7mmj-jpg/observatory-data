艦艇の持続度と中間線越えの割合試作

艦艇は一度出ると数日とどまります。「多い日」が何日続くのか、それが偶然の並びより長いのかを示します。あわせて、軍機のうち中間線越え等に数えられた割合を週ごとに、信頼区間つきで示します。

何が分かるか

  • 艦艇数が「その時点の過去1年の上位10%」を超えた日の連続日数の分布と、いま続いている日数。
  • 多い日が独立に起きると仮定した場合の分布（幾何分布）との比較。長い連続が仮定より多ければ、まとまった展開（滞留）が起きていることを示します。
  • 中間線越え等の機数 ÷ 軍機の機数の週ごとの割合と、その 95% Wilson 信頼区間。

手法

  • 多い日：その日を含まない過去365日の艦艇数（値のある日が180日以上）の90%分位点を超えた日（同じ値は含めない）。基準が時期とともに動くので、全体の水準が上がった時期でも「その時点で多い」日を拾います。
  • 連続：暦日で続いた多い日の数。null または日報のない日で連続を切ります（その日は数えない）。
  • 独立の場合の期待：多い日の割合を p、連続の数を R としたとき、長さ L の連続の期待数 R·(1−p)·pL−1。あわせて「多い日の翌日も多い日である割合」を示します（独立なら p に近くなる）。
  • 割合：週ごとに、中間線越え等と軍機の両方が記載された日だけを合計し、k/n と Wilson の 95% 区間を求めます。

限界

  • 日報の艦艇数は「その時点で台湾周辺にいた数」で、同じ艦が翌日も数えられているのか、入れ替わったのかは分かりません。持続度は「同じ艦がとどまった」ことの証拠ではありません。
  • 中間線越え等が null の日（越えなしとみられる日）を除くので、割合は高めに出ます。null の多さは時期によって違います（1）。両方が記載された日がない週は描いていません。
  • 1機ずつが独立に越えるという二項分布の仮定は成り立ちません（編隊でまとまって動く）。Wilson の区間は実際の不確かさより狭いと考えてください。
  • 「中間線越え等」は、中間線を越えた機と北部・中部・西南・東部の空域に入った機を合わせた数で、書式により含まれる範囲が少し違います。
